 🌊 Nova Launcher Pulse

Your Minecraft, Your Style.

Nova Launcher Pulse is a Minecraft launcher project focused on customization, a modern interface, and convenient game management.

 ✨ Features

- 🎨 **Custom Themes** — personalize the launcher’s appearance.
- 🌊 **Ocean Theme** — a dark interface with cyan accents.
- 🧩 **Mod Management** — manage custom Minecraft mods.
- 🖥️ **Compact Interface** — a clean and space-efficient layout.
- 🚀 **Continuous Improvements** — new features, fixes, and UI enhancements.
